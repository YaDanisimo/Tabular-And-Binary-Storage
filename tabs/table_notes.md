# Table — заметки по реализации

**Статус:** первый прототип. Некоторые проверки и методы ещё не реализованы.

## 1. Внутреннее состояние объекта

| Атрибут | Формат | Назначение |
|---|---|---|
| `self._columns` | `tuple` | Названия столбцов в заданном порядке |
| `self._rows` | `list[list]` | Строки таблицы и значения ячеек |
| `self._types` | `list[type]` | Объявленный тип каждого столбца |

Пример:

```python
_columns = ("name", "age")
_rows = [["Аня", "18"], ["Даня", "19"]]
_types = [str, str]
```

**Важно:** индекс столбца одинаков в `_columns`, `_types` и каждой строке `_rows`.

## 2. Методы класса

| Метод | Принимает | Возвращает | Что делает |
|---|---|---|---|
| `__init__` | `columns`, `rows` | `None` | Проверяет структуру и создаёт таблицу |
| `get_values` | `column: str` | `list` | Возвращает новый список значений столбца |
| `set_values` | `column: str`, `values: list` | `None` | Изменяет значения столбца |
| `get_column_types` | Только `self` | `dict[str, type]` | Возвращает новый словарь типов |
| `set_column_types` | `column_types: dict` | `None` | Преобразует значения и обновляет объявленные типы |

### `__init__(self, columns, rows)`

- Проверяет, что имена столбцов уникальны.
- Проверяет одинаковую длину строк.
- Преобразует названия столбцов в кортеж.
- Использует `deepcopy(rows)`, чтобы создать независимую копию строк.
- Создаёт `_types`, где тип каждого столбца изначально `str`.

### `get_values(self, column)`

1. `column_index` — индекс нужного столбца.
2. `values` — новый пустой список.
3. `row` — очередная строка таблицы.
4. Из каждой строки извлекается значение по `column_index`.
5. Возвращается собранный список.

**Важно:** изменение возвращённого списка не изменяет таблицу, если ячейки содержат обычные неизменяемые значения.

### `set_values(self, column, values)`

1. Проверяет соответствие количества новых значений количеству строк.
2. `column_index` — индекс изменяемого столбца.
3. `i` — номер текущей строки, полученный через `enumerate`.
4. `row` — сама внутренняя строка таблицы.
5. `row[column_index] = values[i]` заменяет значение ячейки.

**Важно:** метод меняет внутреннее состояние объекта, но пока не проверяет типы переданных значений.

### `get_column_types(self)`

Создаёт словарь формата:

```python
{"name": str, "age": int}
```

- `column` — имя текущего столбца.
- `column_type` — его объявленный тип.
- `columns_types` — новый словарь для результата.
- `zip()` перебирает названия столбцов и их типы попарно.

Изменение возвращённого словаря не меняет внутренний `_types`.

### `set_column_types(self, column_types)`

Пример входных данных:

```python
{"age": int, "score": float}
```

**Этап 1 — подготовка.**

| Переменная | Значение |
|---|---|
| `column_types` | Словарь запрошенных преобразований |
| `column` | Название текущего столбца |
| `column_type` | Новый тип, например `int` |
| `column_index` | Индекс столбца |
| `row` | Очередная строка |
| `converted_values` | Преобразованные значения одного столбца |
| `converted_columns` | Словарь всех подготовленных преобразований |

Пример `converted_columns`:

```python
{
    1: (int, [18, 19]),
    2: (float, [85.5, 92.0])
}
```

**Этап 2 — применение.**

- `column_index` — столбец, который изменяем.
- `column_type` — тип, который нужно записать в `_types`.
- `values` — заранее преобразованные значения.
- `i` — индекс строки.
- `row` — внутренняя строка таблицы.

Метод записывает значения только после успешной подготовки всех столбцов. Если на этапе преобразования возникнет исключение, исходная таблица останется неизменной.
