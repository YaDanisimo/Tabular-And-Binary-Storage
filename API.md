## `load_csv(*paths, header=True, encoding="utf-8", delimiter=",", newline="")`

Загружает один или несколько CSV-файлов в объекты `Table`. Пустые строки (все ячейки после `strip()` пустые) отбрасываются **до** обработки заголовка.

**Параметры**
- `*paths: str` — один или несколько путей к CSV-файлам.
- `header: True | list[str] | tuple[str, ...] | None` — как трактовать заголовок:
  - `True` — имена колонок берутся из первой **непустой** строки файла, эта строка в данные не попадает;
  - `list` / `tuple` — использовать переданные имена; длина должна совпадать с числом колонок в первой непустой строке, все элементы — строки; первая строка при этом считается данными;
  - `None` — имена колонок `0, 1, 2, …` (целые числа).
- `encoding: str` — кодировка файла, по умолчанию `"utf-8"`.
- `delimiter: str` — разделитель полей, по умолчанию `","`.
- `newline: str` — параметр `newline` для `open`, по умолчанию `""`.

**Возвращает**
- `None`, если `paths` пуст;
- `Table`, если передан один путь;
- `list[Table]`, если путей несколько.

**Поведение на границах**
- Если после фильтрации строк не осталось, в `Table` передаётся `{}` (пустой словарь, а не список).
- Проверка длины `header` идёт только по первой непустой строке; строки другой длины не валидируются — короткая даст меньше ключей в словаре, длинная приведёт к `IndexError` на `column_names[idx]`.

**Исключения**
- `ValueError` — `header` не `True`, не `None` и не `list`/`tuple`; либо длина `header` не совпадает с числом колонок в первой непустой строке.
- `TypeError` — в `header`-списке/кортеже есть элемент не-строка.
- `FileNotFoundError` — файл не найден.

**Пример**

```python
from tabs import load_csv

table = load_csv("data.csv")
print(table.columns)

tables = load_csv("a.csv", "b.csv", header=None)
print(len(tables))  # 2
```

## `save_csv(table, path="saved_test_files/test.csv", max_rows=None, save_names=True, delimiter=",", encoding="utf-8", newline="")`

Сохраняет `Table` в CSV. При необходимости разбивает данные на несколько файлов по `max_rows` строк.

**Параметры**
- `table: Table` — таблица для сохранения.
- `path: str` — базовый путь. Если оканчивается на `.csv`, эти 4 символа **отбрасываются**:
  - при `max_rows=None` файл создаётся ровно по полученному пути (то есть **без расширения**, если исходный `path` оканчивался на `.csv`);
  - при разбиении части получают имена `<path>_0.csv`, `<path>_1.csv`, …
- `max_rows: int | None` — `None` — сохранить всё в один файл; положительное целое — разбить на части по столько строк; любое другое значение вызывает `ValueError`.
- `save_names: bool` — писать ли строку заголовка, по умолчанию `True`. Заголовок берётся из ключей первой строки данных.
- `delimiter: str` — разделитель полей.
- `encoding: str` — кодировка файла.
- `newline: str` — параметр `newline` для `open`.

**Возвращает:** `None`.

**Исключения**
- `ValueError` — если `max_rows` не `None` и не положительное целое.
- `IndexError` — если таблица пуста: `_save_csv` берёт `rows[0]` для получения имён колонок, а при пустых данных `rows[0]` не существует. Касается обеих веток.

**Пример**

```python
from tabs import load_csv, save_csv

table = load_csv("data.csv")
save_csv(table, "out.csv")                # файл "out" (без расширения)
save_csv(table, "out.csv", max_rows=100)  # out_0.csv, out_1.csv, ...
```

## `load_pickle(*paths)`

Загружает один или несколько pickle-файлов и оборачивает загруженные данные в `Table`.

**Параметры**
- `*paths: str` — один или несколько путей к pickle-файлам.

**Возвращает**
- `None`, если `paths` пуст;
- `Table`, если передан один путь;
- `list[Table]`, если путей несколько.

**Поведение на границах**
- Кодировка, разделитель и `newline` не принимаются: файл читается в бинарном режиме (`open(path, "rb")`).
- Загруженные данные передаются в `Table(...)` как есть. Подходят ли они конструктору — определяется самим `Table`.

**Исключения**
- `FileNotFoundError` — файл не найден.
- `pickle.UnpicklingError` — файл не является корректным pickle.
- Ошибки конструктора `Table`, если загруженные данные ему не подходят.

**Пример**

```python
from tabs import load_pickle

table = load_pickle("data.pkl")
print(table.rows)

tables = load_pickle("a.pkl", "b.pkl")
print(len(tables))  # 2
```

## `save_pickle(table, path, max_rows=None)`

Сохраняет `Table` в pickle. При необходимости разбивает данные на несколько файлов по `max_rows` строк.

**Параметры**
- `table: Table` — таблица для сохранения. Данные берутся через `table.get_data()`.
- `path: str` — базовый путь. Если оканчивается на `.pkl`, эти 4 символа **отбрасываются**:
  - при `max_rows=None` файл создаётся ровно по полученному пути (то есть **без расширения**, если исходный `path` оканчивался на `.pkl`);
  - при разбиении части получают имена `<path>_0.pkl`, `<path>_1.pkl`, …
- `max_rows: int | None` — `None` — сохранить всё в один файл; положительное целое — разбить на части по столько строк; любое другое значение **молча игнорируется**: ни файлов, ни исключения.

**Возвращает:** `None`.

**Поведение на границах**
- В отличие от `save_csv`, некорректный `max_rows` не вызывает `ValueError` — функция просто ничего не делает.
- Пустая таблица не приводит к ошибке: `_save_pickle` пишет то, что вернул `get_data()`, без индексации по `[0]`.

**Исключения**
- Исключений по `max_rows` нет; возможны ошибки `open`/`pickle.dump` и `Table.get_data()`.

**Пример**

```python
from tabs import load_pickle, save_pickle

table = load_pickle("data.pkl")
save_pickle(table, "out.pkl")                 # файл "out" (без .pkl)
save_pickle(table, "out.pkl", max_rows=100)   # out_0.pkl, out_1.pkl, ...
```
