## Импорт таблиц

### load_csv(paths*, headers=True, infer_type=True)
* Загружает произвольное количество файлов, преобразует каждый в Table.
* Каждую ячейку переводит в свой тип: "24" -> int, "True" -> bool и тд.
* infer_type=True: определяет типы столбца (см. П0). По умолчанию str
* headers=True: Первую строку берёт как названия столбцов. Иначе ставит индексы

!!! Если файл был пуст, вернёт (None, [], None)

## Определение типов
Осуществляется с помощью двух функций, которые идут в связке друг с другом.

`def infer(rows: list) -> dict`

* `infer()` принимает на вход строки, вызывает по необходимости `solve_conflict()` и возвращает словарь `{столбец: тип}`
* `solve_conflict()` - определяет тип столбца со значениями, имеющими разные типы и возвращает тип
